🌐 About This Project

This application uses Google Gemini to translate English text into 23 supported languages, delivering clear, natural-sounding speech for every translation. It adapts to your workflow with flexible input options: type directly, upload a file, or extract text from images using built‑in OCR. The result is a smooth, accessible tool designed to make multilingual communication feel effortless and human.

Key Features

🔤 AI‑Powered Translation

Powered by Google Gemini for accurate, context‑aware translations.

🔊 Text‑to‑Speech

Generate natural audio in multiple languages and download the MP3.

📄 File Upload Support

Translate text from PDF, TXT, CSV, XLSX, PNG, JPG, and JPEG files.

🖼️ OCR Support

Extract text from images using EasyOCR before translating.

Tech Stack

  • Google Gemini API
  • Streamlit
  • gTTS (Google Text‑to‑Speech)
  • EasyOCR
  • Python
